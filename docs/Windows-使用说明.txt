杨三海解压 · Windows 版使用说明
版本 0.9.57 ｜ 免安装绿色版
════════════════════════════════════════════

【怎么用】

  双击 yshjy_gui.exe 就能打开（有窗口的那个程序）。
  把视频 / 图片 / 压缩包直接拖进窗口，或者点「选择文件」。

  窗口里的 yshjy.exe 是「引擎」，界面靠它干活。
  这两个文件必须放在同一个文件夹里，别只拷走其中一个。


【第一次打开会有蓝色警告，这是正常的】

  Windows 会弹一个「Windows 已保护你的电脑」的蓝色窗口，
  因为它不认识这个软件（作者没买代码签名证书，那证书一年要几千块）。

  怎么过去：
    点窗口里的「更多信息」→ 再点下面出现的「仍要运行」。

  这个警告只在你第一次运行时出现一次，之后就没了。
  软件本身不联网、不上传任何东西，你可以断网使用。


【命令行怎么用】（不想敲命令可以完全跳过这段）

  在文件夹空白处按住 Shift + 右键 → 「在此处打开 PowerShell 窗口」，然后：

    .\yshjy.exe "某个视频.mp4"            解压
    .\yshjy.exe --list "某个视频.mp4"      先看看里面有什么
    .\yshjy.exe -p "解压码" "某个视频.mp4"  带密码解
    .\yshjy.exe --help                    看完整用法

  yshjy.exe      常用版（日常格式都在，用这个就行）
  yshjy-full.exe 全能版（当前覆盖与常用版一致，等冷门格式补进来才有差别）


【解压到 U 盘 / 移动硬盘】

  默认是解完就报成功。想更保险，可以去「设置」打开
  「解压到U盘/移动硬盘时，等数据真正写完再报成功」——
  打开后会多一步「正在检验落盘」，数据真正写进设备才算完成。
  拔盘前等进度走完、再点「安全弹出」就行。


【卸载】

  绿色版：直接删掉整个文件夹，不写注册表、不留垃圾。
  安装版：设置 → 应用 → 已安装的应用 → 杨三海解压 → 卸载。


【出问题了】

  软件里「设置 → 诊断包」能导出使用记录（已脱敏），方便查问题。
  日志不联网、不上传。
