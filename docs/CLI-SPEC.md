# yshjy 命令行规范（CLI-SPEC）

> 版本：v2（2026-10-17）　适用：v0.5（Linux CLI）
> 目标：终端用户用得爽，脚本能自动化，且与 GUI **功能对等**
>
> ⚠️ **本文是目标规范，不是实现清单。** 当前已实现：
> `解压` / `jy` / `ys` / `--list` / `--rescue` / `-o` / `-p` / `-q` / `-j --jobs` / `--select` / `--json` / `--tail` / `--report` / `--no-paths`；
> 其余见 §3.5 待实现清单。

---

## 一、核心原则

1. **默认行为最省事**：`yshjy 文件` 就够，不带任何参数。
2. **不选后缀、不选格式**：引擎自动识别（见 DESIGN 16.1）。
3. **出错给下一步**：错误信息必须包含"怎么办"，不只说"失败"。
4. **可脚本化**：退出码可判断、`--quiet` 只输出结果、`--list` 输出结构化文本。
5. **与 GUI 对等**：GUI 能做的，CLI 必须有对应开关（见第五节对照表）。

---

## 二、命令结构

```
yshjy [命令] [选项] <文件...>
```

| 命令 | 说明 | 备注 |
|------|------|------|
| *（省略）* | **解压** | 名字即行为，解压无破坏性 |
| `jy` | 解压（显式） | 与 `ys` 对称，脚本里推荐写全 |
| `ys` | 打包（伪装） | 主动创作行为，必须显式输入 |
| `--list` / `-l` | 只列出内容，不解压 | 相当于"预览" |
| `--help` / `-h` | 帮助（新手引导） | 首次运行自动打印精简版 |
| `--version` / `-V` | 版本信息 | |

## 三、完整参数表

### 3.1 通用
| 参数 | 说明 | 默认 |
|------|------|------|
| `-o, --output <目录>` | 输出目录 | 配置里的默认值，否则当前目录 |
| `-q, --quiet` | 只输出结果（脚本用） | 关 |
| `-v` / `-vv` | 详细 / 调试 | 关 |
| `--log <文件>` | 同时写日志 | 关 |
| `--report` | 结束后导出诊断包 | 关 |
| `--no-color` | 禁用彩色（管道/日志友好） | 自动检测 |
| `--config <文件>` | 指定配置文件 | `~/.config/yshjy/config.toml` |
| `-j, --jobs <N>` | 并行任务数 | 1 |

### 3.2 解压相关
| 参数 | 说明 | 默认 |
|------|------|------|
| `-p, --password <密码>` | 指定密码（**日志/回显一律打码**） | 无 |
| `--password-file <文件>` | 密码本 | 配置里的默认 |
| `--no-auto-password` | 不自动从"说明.txt"找密码 | 关（默认会自动找） |
| `--rescue` | 救援模式：损坏也尽量救 | 关 |
| `--only <模式>` | 只解一部分（**实现名为 `--select`**，见 §3.4） | 全解 |
| `-f, --force` | 覆盖已存在文件 | 关（默认自动重命名） |
| `--keep` | 保留中间产物 | 关 |
| `--no-verify` | 跳过完整性校验（快，但危险） | 关（默认校验） |
| `--extract-cover` | 只剥出封面视频/图片 | — |

### 3.3 打包相关（`ys`）
| 参数 | 说明 | 默认 |
|------|------|------|
| `--layout <L1\|L2\|…>` | 数据布局（见 DESIGN 15 矩阵） | `L2`（推荐） |
| `--cover <文件>` | 用作外壳的封面文件 | 内置默认素材 |
| `-p, --password <密码>` | 设置密码（别人解要输，我们用工具自动带） | 无 |
| `--split <大小>` | 分卷（如 `2G`、`500M`） | 不分卷 |
| `--name <显示名>` | 自定义伪装文件名 | 原名字 + `.mp4` |
| `--fake-signatures` | 撒假签名（防扫描器，会降低兼容性） | 关 |
| `--noise` | 加干扰数据 | 关 |
| `--no-notes` | 不生成说明书 | 关（默认生成） |
| `--tweak-time` | 修改时间戳（防炸链） | 关 |

> ⚠️ `--layout L5` / `L6` 会被**拒绝并解释原因**（实测：L5 解压残废、L6 视频播不了）。
> `--fake-signatures` 与 `--layout L3` 同时使用时会额外警告。

### 3.4 v0.5 已实现（新增）

| 参数 | 说明 | 默认 |
|------|------|------|
| `-j, --jobs <N>` | 并行任务数（分片并行，结果仍按任务号排序） | 1（顺序跑，对磁盘最友好） |
| `--select <条件>` | 只解一部分（四种写法见下） | 全解 |
| `--json` | 事件流 + 汇总结论 + 预览结果按行输出 JSON | 关 |
| `--no-smart-dir` | 关掉「智能解压三规则」，永远建同名文件夹 | 关（默认开启智能） |

`--select` 的四种写法：

```bash
yshjy --select "*.exe" 包.mp4        # 通配：不含 / 时匹配**任意层级**的文件名
yshjy --select "游戏数据/**" 包.mp4   # 含 / 时按整个路径匹配，** 跨目录
yshjy --select "1,3,5" 包.mp4        # 按条目序号（就是 --list 里的序号）
yshjy --select required 包.mp4       # 只要必需的：跳过目录与 .DS_Store 之类平台垃圾
```

**多个目标 / 给目录**：目录会递归展开成任务队列（去重、按体积倒序，大的先跑）。
多任务 + `-o` 时每个包解到 `-o/<包名>/` 子目录，避免两个包的文件互相改名。

**批量退出码**：有失败且有成功 → `5`；全失败 → 取第一个失败码；有取消且无失败 → `130`。

### 3.5 v0.8 / v0.9 新增

| 参数 | 说明 | 默认 |
|------|------|------|
| `--lang <语言>` | 界面语言（`zh-CN` / `zh-TW` / `en` / `ja` / `ko` / `ru` / `es`） | 跟随系统语言 |
| `--force` | 跳过解压前的磁盘空间预检 | 关（空间不够就拒绝开始） |
| `--show-config` | 打印当前配置（文件路径 + 每一项现在的值） | — |
| `--import-passwords <文件>` | 导入外部密码本（兼容隐写者的 `PW.txt`：Tab 取第一列，**不过滤中文**） | — |
| `--report [包]` | 生成诊断包（报障用；不给包就只收集环境信息） | — |
| `--no-paths` | 仅配合 `--report`：路径脱敏成 `<path-1>` 这类占位符 | 关（默认含路径） |

**`--report` 的隐私承诺（硬性，见 §八）**：包里**不含**文件内容、**不含任何密码**
（命令行里的 `-p` 值会被抹成 `<已抹掉>`；代理环境变量只记名字、不记值 ——
值可能长成 `http://user:pass@host`）、不含密码本内容（只记行数）与文件名清单（只记数量）。

**进度条**：只在真终端上画（管道/重定向不吐控制字符）；
事件在引擎侧按 100 ms 合并，外壳再节流到 200 ms 重画。

## 四、输出设计

### 4.1 正常输出（默认，带进度）
```
$ yshjy 示例视频.mp4

  🔍 识别：MP4 视频（里面藏着压缩包）
  📦 找到 1 个压缩包  8.59 GB
  ⬇  提取中  ████████████░░░░░░░░  62%   还需约 2 分钟
  🔑 需要密码 → 试「唯ai雪**」✓
  📂 解压中  351 个文件
  ✅ 校验通过   文件数 351/351   耗时 2 分 14 秒
  🎮 主程序：示例包/01/08/2-示例视频2.0/Lake.exe
  📁 输出：/home/你/yshjy-output/示例视频/
```

### 4.2 安静模式（`--quiet`，脚本用）
```
/home/你/yshjy-output/示例视频/
```
> 只输出最终路径；适合 `cd $(yshjy -q 文件.mp4)` 这种用法。

### 4.3 列表模式（`--list`）

**人话版**（默认）：带序号的清单，**序号可直接喂给 `--select`**

```
$ yshjy --list 包.mp4
📦 包.mp4（zip）
   ℹ 其中 1 个带锁 —— 解压需要解压码

     🔒    1.    8.59 GB  示例包.7z.001
             2.    5.55 GB  示例包.7z.002

   合计 14.14 GB / 2 个文件
   解压码：看旁边的「说明.txt」，或 yshjy -p "解压码" "包.mp4"
   只解一部分：yshjy --select "1,3" "包.mp4"
```

**脚本版**（`--json`）：一条 JSON，`entries[]` 里是 index / path / size / encrypted / risky

```
$ yshjy --list --json 包.mp4
{"input":"包.mp4","format":"zip","complete":true,"files":2,"total_size":15171313151,
 "encrypted":1,"hints":["其中 1 个带锁 —— 解压需要解压码"],
 "entries":[{"index":1,"path":"示例包.7z.001","size":8590199667,"is_dir":false,...}]}
```

**安静版**（`--quiet`）：每行一个路径（`awk` / `xargs` 友好）

> 支持的格式：ZIP / 7z / RAR / 单流。RAR 的大小拿不到（库没暴露）会标 `complete=false`；
> TAR 家族暂不预览（顺序格式要扫完整流）。

### 4.4 进度条规则
- 只有 TTY 且非 `--quiet` 时才画进度条；管道输出时自动改为逐行日志。
- 进度刷新频率限制 100ms（与 GUI 事件流一致）。
- **永不清屏**（竞品清屏冲掉日志的坑，见 UI-SPEC 9.3）。
- 大文件必须显示：百分比 + 字节数 + 预计剩余 + 当前文件名。

## 五、CLI 与 GUI 功能对等表

| 能力 | CLI | GUI（桌面/手机） |
|------|-----|-----------------|
| 解压 / 打包 | `yshjy` / `yshjy ys` | 主按钮 |
| 预览内容 | `--list` | 列表区 + 勾选框 |
| 选择性提取 | `--only <模式>` | 勾选条目 |
| 只剥封面 | `--extract-cover` | 长按菜单「只看视频」 |
| 密码 | `-p` / `--password-file` | 密码输入框 + 密码本 |
| 救援模式 | `--rescue` | 失败页的「尽量救出来」 |
| 批量 | 多文件参数 / 通配符 | 多选 + 队列 |
| 布局选择 | `--layout` | 高级设置面板 |
| 导出诊断 | `--report` | 设置页「导出诊断信息」 |

| 后台运行 | `&` / `nohup` | 系统通知 + 后台任务 |

**原则**：GUI 独有的只有"拖拽、手势、通知栏"这类平台交互；**引擎能力一律可由 CLI 触达**。

> v0.8 / v0.9 新增的选项以 §3.5 为准（`--lang` / `--force` / `--show-config` /

```
杨三海解压 (yshjy) v0.1.0
把「伪装成视频/图片的压缩包」一键还原成能用的文件

用法
  yshjy <文件>                解压（默认）
  yshjy jy <文件>             解压（写法完整，脚本推荐）
  yshjy ys <文件或文件夹>      打包成伪装文件
  yshjy --list <文件>         先看看里面有什么
  yshjy --help                看这份帮助

常用例子
  yshjy 示例视频.mp4          解开藏在视频里的压缩包

  文件坏了？      加 --rescue 试试，能救多少救多少
```

## 七、退出码（脚本可判断）

| 码 | 含义 | 典型场景 |
|----|------|---------|
| `0` | 成功 | 正常完成 |
| `1` | 一般错误 | 路径不存在、磁盘不够、没权限、内部错误 |
| `2` | 用法错误 | 参数不对（只有外壳用得上） |
| `3` | 不是压缩包 | 认不出里面有压缩包 |
| `4` | 密码问题 | 需要密码 / 密码不对 |
| `5` | 部分成功 | 救出了 340/351 个文件 |
| `130` | 用户取消 | 主动中断（**已解出的文件保留**） |

> **实现说明（台账 §7.6 的教训）**：退出码常量只定义在引擎里
> （`yshjy::error::exit_code`），CLI 与 GUI 都从那里取 ——
> 7-Zip 当年就因为两个壳各算一份而行为不一致。
> 单个任务的结论由 `Outcome::exit_code()` 裁决，批量由 `BatchReport::exit_code()` 统一汇总。

## 八、安全与隐私（硬性）

1. **密码永不回显**：命令行里输入过密码后，日志/进度/错误里一律显示为 `1234**` 或 `●●●●●●`。
2. **`--password` 在 `ps` 里可见**：帮助文本中提示"更安全的方式是用 `--password-file` 或交互输入"。
3. **诊断包不含密码与文件内容**（见 BACKEND-SPEC ④；**v0.9 已实现并实测通过**）：
   命令行里的 `-p` 值 → `<已抹掉>`；代理环境变量**只记名字、不记值**（值可能长成
   `http://user:pass@host`）；密码本**只记行数**；文件名清单**故意不含**（只给数量）；
   `--no-paths` 时路径换成 `<path-1>` 这类占位符。
   实测结果：带假密码生成一份，包里 **0 次**出现；`--no-paths` 下真实路径 **0 次**出现。
4. **解出可执行文件时高亮提醒**。
5. **拒绝危险参数组合**（如 `--layout L5 --password` → 报错并说明）。
