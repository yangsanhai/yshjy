## 一、共享改动（Linux 行为也会变，必须验）

### 1. ZIP 条目时间 −8 小时的问题修了（★最需要知道）

- **文件**：`src/extract.rs`（`还原条目属性`）
- **原来**：ZIP 里存的是 DOS 本地墙钟，转 Unix 秒时直接 `civil_to_unix`（当 UTC 看）——
  在东八区解出来的文件时间**整体 +8 小时**。Windows 上实测：源 18:50 → 解出次日 02:50；
  和 `7z x` 解同一个包也差 8 小时。
- **现在**：减掉 `restore::本地偏移秒()`，与打包端（`unix_to_civil_本地`）对齐。
- **验证**：打一个包、设一个已知 mtime、解回来对时间；或拿任意 ZIP 与 `7z x` 对比。
  本次实测：往返一致（DOS 2 秒精度内）、与 7z 逐秒相同。
- **注意**：Linux 上也是同一个 bug、同一处修，属于「两边一起变正确」。

### 2. 包内非法字符 `* ? < > " |` 现在会被拒

- **文件**：`src/safety.rs`（`resolve_safe` ③'）+ 新测试 `拒绝windows非法字符`
- **依据**：`refs/tech/对比-安全与健壮性.md` §A3（7zip / PeaZip / XAD 三家一致）。
- **行为变化**：这种条目会**跳过**（错误码 `INVALID_ARGUMENT`，reason=`windows_invalid_char`），
  与既有的保留名 / 冒号 / 尾随空格点同一套「Windows 安全名」策略。
- **Linux 影响**：Linux 上这些字符本来合法；如果 Linux 用户确实需要解出这种名字，需要再讨论。
  本次按「包多半来自 Windows」的统一策略处理了，测试通过。

### 3. `--split` 的 `.001` 裸切分现在能打开

- **文件**：`src/job.rs`（新增 `as_raw_slices`；`as_7z_volumes` 补 7z 魔数校验）+ 新测试
  `裸切分的伪装包能认出并解开`
- **行为变化**：
  - `x.mp4.001/.002/…` 按序拼成逻辑流 → 走普通 ZIP 定位；`--list`、真解、GUI 预览都通；
  - 编号形式**必须第一块真是 7z 头**才认成 7z（原来只看文件名，会把裸切分误判成 7z）。
- **缺卷**：报「分卷不齐」，不会静默。
- **参考**：`refs/tech/对比-同名技术择优.md` §8（unar `XADZipParser.m:60` 的 `.zip.001` 规则）。

### 4. 引擎侧两处「只看 HOME」改成 `paths::home()`

- `src/i18n.rs`（外部语言包目录）、`src/report.rs`（`--no-paths` 抹家目录）、
  `src/api.rs`（`hello.disk` 的目标路径回退）。
- **Linux 行为不变**（`paths::home()` 在 Linux 上仍优先 `HOME`）；只是 Windows 不再失效。

### 5. 新增 7 语言键 `cli.report_done_hidden`

- `locales/*.toml`：`--report --no-paths` 已经脱敏时，不再劝你「请加 --no-paths」。
- **注意**：7 个语言文件的键集合应保持一致；Linux 侧的语言包完整性测试/脚本请复核。

### 6. GUI 传输层并发写竞态（Linux 同样中招）

- **文件**：`gui/lib/transport/engine_transport.dart`
- **原症状**：`hello`（外壳）与 `list`（首页打开包）同时写引擎 stdin，`flush()` 会把 sink
  绑住，另一条 `writeln` 抛 `StreamSink is bound to a stream` → 界面**永远停在「正在识别…」**。
  Windows 上约一半概率复现；Linux 也具备同样的触发条件。
- **修法**：`writeLine` 串行化（写整行 + flush 一次只跑一个）；首页 `_open` 补兜底 catch
  （传输层异常落到错误页，不再吊死）。

### 7. GUI 打包页支持拖放 + 两页拖放互抢修复

- **文件**：`gui/lib/pages/pack_page.dart`（新增 DropTarget + `_addDropped`）、
  `gui/lib/pages/home_page.dart`（`acceptDrop`）、`gui/lib/app_shell.dart`（按前台页开关）。
- **行为**：打包页可拖文件/文件夹进输入列表（去重、自动推输出名）；首页拖放保持原样。
- **补的坑**：IndexedStack 里两页的 DropTarget 都铺满窗口，不按前台页关掉会互相抢。
- **顺带修**：打包页输入列表标题原来只按 `/` 取文件名（Windows `\` 路径会显示整条路径）。
