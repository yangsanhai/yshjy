## 四、暂缓：边解压边删源（调研已完成，随时能捡）

你说先不加，那这条就停在这儿。调研结论留在 **`docs/INPLACE-EXTRACT.md`**，一句话概括：

- 硬盘上的文件**只能从尾巴砍短**，砍不了开头和中间；而解压是从前往后读的，读完的部分正好在砍不掉的那头。
- `hatchzip`（Rust）的办法是**倒着解**：从包里最后一个文件往回解，每解一批砍一次尾巴，
  砍之前先把尾部索引另存一份。它靠这套把「包 + 解出」的峰值降到接近「解出」。
- 我们抄不了倒着解那套（解压库全是单向流式的），但能做另外两档：
  **① 分卷读完就删这一卷**（最稳，我们的分卷支持现成）；**② 打洞**（Linux 上把已读区间挖掉释放）。
- 铁律：默认关 / 先落盘再释放（顺序反了就是断电双丢）/ 有失败或取消就一字节不删 / 分卷整组。

## 七、全平台：零成本路线（2026-10-28 你定的）

你的实际情况：**没有 Mac 设备，也不买 Apple 开发者账号（99 美元/年）**。所以路线定为：

- **不出**官方签名版、**不上架** App Store、**不做**公证、**不买**代码签名证书、**不买** Mac 设备 —— 花的钱 = 0。
- **要出**：公开源码 + 免费 CI 编出**未签名**的 Windows / Android / macOS 包 + iOS 由懂的人自编自装。

三条依据（都查证过）：
1. GitHub Actions 对**公开仓库完全免费**，连 macOS 那台云 Mac 也免费 —— 所以不需要你有 Mac 设备。
2. macOS 未签名软件**不需要开发者账号**就能给人用，用户首次右键 →「打开」即可（99 美元只为了上架和公证）。
3. iOS 用**免费 Apple ID** 就能装到自己 iPhone（7 天有效期，可续）—— 99 美元只为了长期/上架/TestFlight。

六步推进（详细验收标准在 `docs/TODO.md` 的「全平台（零成本路线）」节，**一次只做一行**）：

| 步 | 做什么 | 花钱 | 前置 |
|---|---|---|---|
| ① | 仓库上 GitHub（公开）+ CI 骨架 | 0 | 需要你一次授权推送 |
| ② | Windows 平台目录 + 出 zip（未签名，用户点「仍要运行」） | 0 | ① |
| ③ | Android 平台目录 + APK（自己生成 keystore；**分区存储权限是重点**） | 0 | ① |
| ④ | macOS 未签名 dmg（靠 CI 的免费 Mac 机器编） | 0 | ① |
| ⑤ | FFI 层（`src/ffi.rs`，现在只有设计文档） | 0（花时间） | ④ 之后任意时候 |
| ⑥ | iOS 工程 + `BUILD-iOS.md`（给愿意自己编的人，写清 7 天有效期） | 0 | ⑤ |

体验上的代价（说在前面）：未签名包第一次打开要手动允许一次；iOS 免费账号 7 天过期要重装；
Windows 首次运行会有「未知发布者」提示点「仍要运行」。这些都不影响功能。

参考对象：`rustdesk/rustdesk`（Rust + Flutter 全平台，打包脚本与 CI 矩阵齐全）、
`localsend/localsend`（Flutter 全平台，Android 存储权限处理得干净）。
