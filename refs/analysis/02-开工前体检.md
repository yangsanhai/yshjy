## 一、七个维度逐项体检

### 1️⃣ 产品 / 需求　80%
**已有**：用户画像、场景、功能清单（解压 12 项 + 打包）、三端界面设计、竞品分析（37 个工具）
**缺口**：
- ❌ **v0.1 范围没切** —— 功能列了 12+ 项，必须切出「最小可用」（见第四节建议）
- ❌ 成功标准未定义（怎么算"做成了"？）
- ❌ 没有真实用户测试计划
- ⚠️ 竞品只是"读报告"，我们自己没实际用过它们

### 2️⃣ 技术可行性　40%　⚠️ 最大风险
**已有**：格式支持矩阵、6 个项目源码分析、核心算法原型（Python 已验证 ZIP 偏移反推）
**缺口**：
- 🔴 **Rust 侧一行代码都没跑过！** 三个关键依赖全部未实测：
  - `zip2` 能不能处理我们这种"偏移差 2355200"的 ZIP？
  - `sevenz-rust2` 能不能处理 **加密 + 分卷** 的 7z？
  - `rars` 能不能处理 **加密 RAR**？
  - → **必须做 1~2 天技术验证（spike），否则方案可能被推翻**
- ❌ 架构设计文档（"三层"只是概念，缺模块划分/接口/数据流）
- ❌ 性能目标（8GB 文件解压要多久？内存上限多少？）
- ❌ GUI 框架未定（Flutter vs egui）
- ❌ 错误处理 / 日志设计

### 3️⃣ 测试数据　10%　⚠️ 第二大缺口
**缺口**：完全没有测试样本，无法开发和回归测试
**需要**：
```
正常包   ZIP/7z/RAR/TAR/gz/xz/zst/bz2（含加密、分卷、单文件/多文件）
伪装包   隐写者模式A(旧版裸追加) / 模式A(1.3.x free原子) / 模式B(free内嵌)
         MKV附件轨 / apate / PolyZip / copy #b
异常包   损坏的 / 截断的 / 缺分卷的 / 假签名污染的 / 目录表被改的
特殊    中文密码 / >4GB / ZipCrypto / AES-256 / 空密码 / 头加密(-mhe=on)
```
**好消息**：隐写者的原理我们已完全摸清（还有可跑的探针脚本），**可以自己生成测试样本**。

### 4️⃣ 法律 / 合规　50%
**已有**：开源红线（RAR 只解不压）+ `rars` 解决了许可问题
**缺口**：
- ❌ 依赖许可证全清单（个别候选是 GPL-3.0 / LGPL，需评估）
- ❌ 项目自身许可证未定（建议 MIT，与同类一致）
- ❌ 免责声明未写（打包功能可能被滥用）

### 5️⃣ 命名 / 品牌　30%
- ⚠️ **crates.io 的 `unbox` 已被占用**（且是同类工具，3349 下载）
- ✅ 可用备选：`unbox-tool` / `ubx` / `unboxer` / `polyunbox` / `arkbox` / `unpacker-rs`
- GitHub 仓库名可与 crate 名不同（不冲突），但为免混淆建议统一
- ❌ 没检查过商标/social 账号占用

### 6️⃣ 发布 / 社区　20%
- ❌ GitHub 远端仓库未建
- ❌ README（中文优先 + 英文）未写
- ❌ 发布/宣传计划未定（B站/论坛/V2EX/Reddit？）
- ❌ FAQ / 使用文档未写

### 7️⃣ 安全设计　20%
- 🔴 **Zip Slip 路径穿越防护**：报告发现隐写者自己就有这个洞（`sanitize_path` 隐患），**我们必须防**，否则用户被恶意包写到目录外
- ❌ 解出可执行文件的安全提示（这类资源是恶意软件传播重灾区）
- ❌ zip bomb / 内存耗尽防护（7z 库的内存限制 `usize::MAX/1024` ≈ 等于没有，恶意 LZMA2 字典可 OOM）
- ❌ 解压路径非法字符/超长路径处理

## 二、最致命的 3 个缺口

| # | 缺口 | 影响 | 补的代价 |
|---|------|------|---------|
| 1 | **Rust 技术验证没做** | 方案可能被推翻（如某依赖不支持分卷+加密） | 1~2 天 |
| 2 | **测试数据集为零** | 没法开发、没法回归测试 | 半天（可自动生成） |
| 3 | **命名未定**（crates.io 冲突） | 越晚改越麻烦（改包名=改代码+文档） | 10 分钟 |

---

## 三、建议的后续动作顺序

```
1. 【定名】10 分钟      → 定 crate 名 + GitHub 仓库名
2. 【造样本】半天        → 用隐写者源码生成全套测试数据
3. 【技术验证】1~2 天    → Rust 里跑通 zip2/sevenz-rust2/rars 最小样例（关键！）
4. 【架构设计】半天      → 模块划分 / 接口 / 数据流 / 错误处理
5. 【建仓库】1 小时      → GitHub 仓库 + README 骨架 + LICENSE + 免责声明
6. 【写 v0.1】           → 开工
```

## 四、v0.1 范围建议（切到最小可用）

**必做**
```
识别    尾部 EOCD+concat / free 原子 / local header 救援（三路）
提取    流式提取，不写垃圾段
解压    ZIP/ZIP64 · 7z · RAR(只解) · TAR · GZIP · XZ · ZSTD · BZIP2
分卷    自动串联
密码    密码本 + 中文 GBK/UTF-8 自动纠错
校验    SHA-256 + 文件数
体验    白话进度提示
安全    Zip Slip 防护 + 内存上限
```

**推迟到 v0.2+**
```
预览挑选 / 批量 / 断点续传 / 救援模式 / 打包 / GUI / Windows / 手机
```
